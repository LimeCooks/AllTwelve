# Reports and film evidence

Reports now select a saved film by ID or explicitly combine all saved films. Failed or incomplete reads show an error with retry; aggregate reads never publish partial totals. Reports show the source and unit, unknown-unit clip count, missing yardage samples and actual down/distance groups. The matrix is a semantic table with contained horizontal scrolling on phones. Dataset explanations are collapsed by default.

Yardage accepts only an explicit number, optionally followed by yards/yd/yds, or a gain/loss phrase. Clock values, down descriptions, touchdown text and arbitrary embedded numbers are not guessed as gains. Positive yardage is labelled as yardage, not offensive/defensive success. Missing samples show a dash. Tied calls are identified and unnamed clips are not represented as saved plays. CSV uses the same source, unit and calculated rows and escapes spreadsheet formulas in user-entered text.

Opening Gameplanning carries the selected film ID or all-films scope. Saving a plan stores its evidence scope alongside existing objectives, selected observations and call-sheet references. Legacy plans retain their records and default to all films. Film evidence loads independently: an unavailable/deleted source does not hide the saved plan, and the owner can retry or choose all films. Observations follow the plan's selected unit and identify their source film.

Validation: 37 automated tests passed, including exact and aggregate source loading, partial failures, malformed responses, strict yardage parsing, missing data, ties, unit filtering and safe CSV. Type checking passed. Local browser checks used two disposable films: the older film's +8 and -2 averaged 3.0, Q1 12:00 was excluded, and combined films averaged 15.3 from three explicit yardage entries. Selecting an observation saved the older film ID, which reopened after navigating away; returning to Reports retained that source. At 390px, the 650px table stayed inside its 311px scrolling container without page overflow. Test files, film records and plan changes were removed; the exact original local plan row was restored. No test records were added to the hosted pilot.

Remaining: this is a descriptive report, not opponent prediction, a success-rate model or automatic scouting advice. All-films reads currently fetch each film separately; large libraries need a bounded server-side report endpoint. Multiple separately named gameplans, richer filters, observation pagination and direct linked-clip navigation remain future work. Physical-device coaching workflows and saved-file cross-device checks are still handoff gates.
